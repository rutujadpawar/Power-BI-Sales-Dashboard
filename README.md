
# Sales Analysis Dashboard – Power BI

## Project Overview
An interactive Sales Analysis Dashboard developed using Microsoft Power BI to analyze sales performance and identify business trends.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Excel / CSV Dataset

## Dashboard Features
- Top 5 Products by Net Sales
- Net Sales vs Target by Region
- Sales Distribution by Customer Segment
- Year-wise Sales Analysis (2023–2025)
- Interactive Year Slicer

## Key Objectives
- Analyze sales performance.
- Identify top-performing products.
- Compare regional sales against targets.
- Understand customer segment contribution.
- Track sales trends over time.
